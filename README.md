# Bunon (বুনন)

A web platform that lets handloom weavers and cooperatives in Bangladesh sell directly to customers, cutting out middlemen for fairer profits. Customers can verify product authenticity through QR passports.

## Features

- Weaver onboarding, admin verification, and craft seals
- Product listings, design registry (AI look-alike detection), and QR passports
- Custom orders with quotes from matched weavers and staged payments
- Cooperative group buying, micro-loans, and revenue sharing
- Courier tracking and dispute management

## Tech Stack

Spring Boot (Java 17+), Spring MVC, Spring Data JPA, Spring Security, Thymeleaf, Bootstrap, MySQL 8, Maven, Python FastAPI (AI service)

## Run

```bash
git clone https://github.com/USER/REPO.git
cd REPO
mvn spring-boot:run
```

Requires Java 17+, MySQL 8, and Python 3.10+ (for the FastAPI service).
